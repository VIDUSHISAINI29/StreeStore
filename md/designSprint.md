# Definition of Done

Sprint 1 is complete when:

- Every component is reusable.
- Every color uses variables.
- Every text uses text styles.
- Every spacing follows the 8px system.
- Every page is built from components.
- Desktop and mobile designs are complete.
- Interactive prototype is functional.
